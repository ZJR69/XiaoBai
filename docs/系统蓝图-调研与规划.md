## 二、系统全景蓝图

系统命名（暂用）：**外置大脑 / Personal Context OS**

### 设计哲学
1. **单一事实来源**：所有事情只有一个权威记录处，脑子里可以放心「放下」
2. **捕获零摩擦**：任何输入 5 秒内完成，先记下来再分类
3. **消化回路必须闭合**：进来的信息要么被消化、要么被明确放弃，不允许无限囤积
4. **半自动契约**：AI 建议、你确认，AI 永不偷偷执行
5. **做减法的智能体**：事情太多时帮你砍任务、排优先级，而不是堆更多

### 分层架构

```
┌──────────────────────────────────────────────────┐
│ L1 统一捕获层                                      │
│  · 全局快捷键速记（文字，后续可扩展剪藏/截图）         │
│  · 浏览器书签导入（先把囤积的存量收进来）             │
│  · 手动录入（上课笔记、会议要点）                    │
└──────────────────┬───────────────────────────────┘
                   ▼
┌──────────────────────────────────────────────────┐
│ L2 收件箱 Inbox（唯一待处理区）                     │
│  · AI 自动分类建议：任务/知识/生活/灵感/垃圾          │
│  · 你一键确认归档（每晚 10 分钟清理仪式）             │
└──────────────────┬───────────────────────────────┘
                   ▼
┌──────────────────────────────────────────────────┐
│ L3 个人 Context 库（核心资产）                     │
│  ├─ 项目与任务：每件事带「进展日志」                 │
│  │   （这正是 P2 的解：事情的发展全程落文字）          │
│  ├─ 知识库：学习资料+收藏，自动打标签、去重、归档      │
│  ├─ 生活事务：快递/房间/习惯，时间触发提醒           │
│  └─ 状态日志：每日简报里的自我记录（情绪功能待定）     │
└──────────────────┬───────────────────────────────┘
                   ▼
┌──────────────────────────────────────────────────┐
│ L4 智能体服务层（半自动）                           │
│  ├─ 每日简报：今天做什么 + 并行度预警 + 回顾什么      │
│  ├─ Context 打包器：针对某件事一键生成完整背景        │
│  │   给老师/学长/其他 AI 同步用                      │
│  ├─ 温和收束：任务过载时主动建议砍/延/委派           │
│  ├─ 消化回路：收藏内容间隔重现（间隔复习机制）         │
│  └─ 生活兜底：时间/事件触发的琐事提醒                │
└──────────────────────────────────────────────────┘
```

### 三个核心创新设计（针对你的独特痛点）

**① Context 打包器（解 P2）**
- 每个项目/任务维护结构化进展日志：背景 → 关键决策 → 当前状态 → 下一步
- 任何时刻需要求助/协作时，一键生成该事的背景摘要
- 也可以直接喂给其他 AI：「这是这件事的全部上下文，帮我……」

**② 每日简报（解 P1/P4/P6）**
- 每天打开电脑第一屏：今日三件事（主任务）+ 生活杂务提醒 + 本周回顾
- 并行度预警：当前活跃任务数超过阈值时提醒你「该收束了」
- 配合温和收束策略，做减法而不是加法

**③ 消化回路（解 P3）**
- Inbox 不清空，知识不算入库
- 入库内容进入间隔重现队列（类似 Anki 但更轻）
- 定期「收藏坟场清理」：超过 N 天未消化的收藏，AI 建议放弃或归档
